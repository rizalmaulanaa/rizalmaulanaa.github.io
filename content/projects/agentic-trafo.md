A proof of concept for **PLN**: an agentic AI that operators can ask about the condition of a fleet of power transformers (*trafo*) — temperatures, load, active alerts, thresholds, maintenance history — and that responds with **active recommendations**, not just numbers.

**How it fits together**

Operator → monitoring dashboard → agent API (FastAPI + LangChain) → MCP Toolbox → TimescaleDB. When an answer is clearer as a picture, the agent writes a Mermaid or Vega-Lite spec and the render service returns it as an image for the chat.

**Design decisions**

- **Read-only by construction.** The agent never touches the database directly. It reaches data only through the MCP Toolbox, which connects with a least-privilege read-only role.
- **Governed tools, not free SQL.** Every query the agent can run is declared up front as a parameterized tool, so the same toolset can also back dashboards or other agents.
- **Safe charts.** Diagrams and trend charts are rendered from code by a Kroki service — nothing generated by the model is ever executed.
- **Time-series first.** Sensor readings live in a TimescaleDB hypertable, seeded with realistic dummy data (daily load cycles plus injected anomalies) for the PoC.

**What's next:** ingesting real transformer data, an alerting engine that writes alerts continuously, human-in-the-loop write actions (acknowledging alerts, creating work orders), and correlating AI-CCTV events with sensor readings.
